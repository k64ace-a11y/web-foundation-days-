About QuickNotes

QuickNotes is a lightweight note-taking app designed to help you capture ideas the moment they appear. It keeps your thoughts organized without getting in the way.

How to use QuickNotes

  1. Open the Home page and type your note into the input field.
  2. Press the Add Note button to save it to your list.
  3. Review your saved notes in the Your notes section.

Features

  • Simple, distraction-free interface
  • Instant note creation
  • Lightweight and fast
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Add note
Esc Clear input field
Ctrl + D Delete selected note
